# Fit Option · Landing

Página de una sola pantalla para Fit Option (repostería fit, Bogotá).

## Antes de publicar
Abre `index.html`, ve casi al final y cambia en **CONFIGURACIÓN**:
- `NUMERO_WHATSAPP`: tu número con 57, sin + ni espacios (ej. 573001234567)
- `INSTAGRAM`: tu usuario sin @

## Cambiar textos o fotos
- Los textos se editan directamente en `index.html`.
- Las fotos están en `img/`. Para cambiar una, súbela con el mismo nombre.

## Publicar en Vercel
1. En GitHub crea un repositorio nuevo (ej. `fit-option`) y sube `index.html`, `README.md` y la carpeta `img`.
2. En Vercel: **Add New → Project → Import** el repositorio → **Deploy** (sin cambiar ninguna configuración).
3. Te queda un link tipo `fit-option.vercel.app`. Cada cambio que subas a GitHub se publica solo.
